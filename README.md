# Lucrium Panel

Локальное десктоп-приложение (exe для Windows) — «удалённый пульт» управления воркером Lucrium. Регистрации нет, панель **ничего важного не хранит**: всё состояние живёт в воркере на VPS. Панель можно закрыть — воркер продолжает работать.

> **Статус:** скелет. Репозиторий создан, реализация — по дорожной карте ниже.

## Что это

- **Экран подключения:** ввод адреса и токена воркера (токен печатает `install.sh`), инструкция с командой установки.
- **Дашборд:** статус воркера (онлайн, uptime, версии), сводка по аккаунтам и сессиям.
- **Аккаунты:** адаптивная форма под платформу (FunPay — `golden_key`, PlayerOK — `access_token`, GGsel — `api_key` + `seller_id`), привязка прокси, capability-матрица (фронт скрывает недоступные действия).
- **Чаты / заказы / события:** live-ленты per-аккаунт из `HubEvent`.
- **Лоты:** чтение и базовое управление (цена, вкл/выкл).
- **Плагины:** установка zip-архивом, настройки — формы, автоматически сгенерированные из JSON-схемы манифеста, логи live.
- **Резерв:** экспорт/импорт состояния, ротация токена.

## Стек

- **Бэкенд:** Python 3.12+, FastAPI на `127.0.0.1` (только UI и локальный кэш), WSS-клиент к воркеру.
- **Фронтенд:** React 18, TypeScript, Vite, Tailwind + shadcn/ui, TanStack Query, Zustand.
- **Сборка exe:** GitHub Actions + PyInstaller/Nuitka → GitHub Releases, авто-проверка обновлений по GitHub API. Учесть false positive антивирусов → подпись кода либо Nuitka.
- Модели протокола — только из [`lucrium-protocol`](../lucrium-protocol).
